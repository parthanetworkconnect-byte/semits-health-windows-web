# SEMITS Health V524 R2 — Medical History and Seven-Day Review Trial

## Included
- 15+ flexible dietary choices with additional food culture and allergy/restriction notes.
- Encrypted (local browser) structured test records of conditions, prescribed/OTC medicines, supplements, allergies and clinical notes.
- Seven-calendar-day, on-demand weekly summary including logged weight, sleep, fluids, activity, symptoms and missing days.
- Export weekly summary in **plain text** (unencrypted): store it responsibly. Encrypted vault backup still available.
- No external AI requests, no medical prescription logic, no automatic emails. Saving a profile/check-in/history entry persists the ciphertext in this browser until storage is cleared.

## Not implemented / important limitations
- No PDF/X-ray/scan/blood-test extraction, clinician-confirmed lab mapping, medication interactions, drug-food contraindication decisions, or automatic source-comparison engine.
- No account authentication, per-person family identity isolation, secure clinical database or synced mobile account.
- No online WHO/Mayo/WebMD live integration. External research source verification and regulatory review are required for a future production system.
- Not a medical device, diagnostic tool, medication advice or validated health plan. Use SYNTHETIC test records only.
- Not a background scheduler: weekly report refreshes when user opens Healthy Living; download manually. The exported TXT is unencrypted.

## Run
Extract to a NEW folder; double-click START_SEMITS_HEALTH_V524.bat. Open Healthy Living, unlock the existing test vault, add a profile, medical history entries and daily check-ins. Download the report under Section 4.

## Existing baseline
V522/V523 R3/V524 R1 archives were not modified. The local existing encrypted vault database is re-used; create an encrypted backup before testing major changes.
