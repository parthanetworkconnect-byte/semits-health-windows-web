# V9.1 changes (Medical Intelligence milestone)
- Added new Medical Intelligence view while retaining original V9 menus/data.
- Added human-verified medical document notes, safe condition/medication matching, source citations, per-person reports, and TXT export.
- Added limited offline guideline reference library (ADA 2026 and NIDDK).
- Added localhost server for PDF text extraction with pypdf, without remote API calls.
- Added explicit safety/privacy limitations.
- No true live literature search, clinical AI, medical image interpretation, patient cohort matching or automatic physician-authored recommendations.
